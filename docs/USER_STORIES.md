# User stories

- As a customer I can register, save addresses, search services, book a free slot, pay, and review.
- As a provider I can register, upload an ID, wait for approval, set price, hours and areas, accept a job, and assign a technician.
- As a technician I can see only my jobs, mark arrival, add photos, and complete the job.
- As an admin I can approve providers, watch revenue, handle complaints, manage coupons and plans, and export CSV.
- The same slot cannot be booked twice. A customer cannot open another customer's booking.
